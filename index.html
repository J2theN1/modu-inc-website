What Modu can do

Real capabilities, today—system health, automation, game dev pipelines, knowledge graph, and more. 90+ API routes, 100+ commands (modu check, audit, analyze, verify, invoke --list), dozens of tool groups.

System & PC

System health, GPU monitor, processes, disk, time, username. Checks and audits: modu check system | gpu | api | all, modu audit apis | ecosystem | fixes. Run shell, browse web, file ops, clipboard, vision (see window, capture screen).

Unreal / UE5

Launch Unreal, query level, scene report, viewport capture. Commands: unreal-status, unreal-message-log, unreal-diagnose-remote, unreal-fix-and-capture, war-survival-launch, and more. Vehicle and asset pipeline: export to OBJ/FBX, import to Unreal, place in level. UE5 console help: searchable by name or help text, categories (Lumen, Physics, Renderer). Remote Execution for in-editor Python.

Blender

Run bpy in Blender (create, export, render). Map builds, 3D assembly, texture pipeline. CLI: modu blender free-setup, extensions, catalogue. Manual search, headless render, export to FBX/OBJ/GLTF; Blender MCP for execute, render, create model, export.

Game of Life & USS

Run and discover Conway’s Game of Life patterns (gliders, guns, oscillators). USS knowledge graph: query topology, relationships, semantic search. Memory, USS discovery, and learning are in the loop for every tooled conversation—not just this card.

Self & tools

Query self (“what can you do?”). Execute Modu commands by name: health-check, gpu-monitor, unreal-capture-viewport, and 100+ more. Otto: impossible problems, apply solution (otto_solve_impossible, otto_apply_solution). Function library: create, compose, list, analyze, download from GitHub, synthesize from knowledge. C++ tools: check memory, improve code, generate.

Discovery & verify

Discovery, analysis, benchmark, exercise (usage and deep)—modu invoke run.discovery, exercise.deep—often without starting the API. Verify tools, unification, scaffolding. Vision smoke test, PC ops deep orchestration, scenario runner for success and quality.

How we build

Quality and success mean real, verifiable outcomes—not assumed, not placeholders.

  • Verify, don’t assume — After every action we check the outcome: actual window captured, actual file saved, actual tool output in the reply.
  • Real data only — No fake counters or synthetic metrics. We use real data from the system, API, and tools.
  • LLM-driven tool choice — The brain gets the full tool catalog and decides. We improve prompt and parsing, not keyword shortcuts.
  • Fix at the root — When something breaks we find the regression and fix it there, not layer workarounds on top.
  • Procedures as contract — Steps are the source of truth. We execute them and report what actually happened.

Pipeline & Game

Building a WW2 game the Modu way—and proving that local AI can drive a full creative pipeline.

War Survival Hybrid

Single-player war simulation sandbox: RTS layer + FPS/third-person + squad command + survival + base building + manufacturing on one persistent map. Unreal 5.5. WW2-era vehicles, environments, and props—all integrated via the Modu pipeline.

The Modu pipeline

What’s special is the process. We don’t just use AI for chat—we put Modu in the loop: export assets to OBJ/FBX, import into Unreal, query level, capture viewport, fix lights, run scene reports. Blender builds maps and assemblies; Modu orchestrates commands and verification. One request → full execution → verified result.

In practice

Modu runs real commands: unreal-launch, unreal-query-level, unreal-capture-viewport, unreal-fix-and-capture. Checks and audits via modu check and modu audit. The same pipeline that builds our game is the one we’re proving for professional Blender and Unreal workflows—doing more with less.
